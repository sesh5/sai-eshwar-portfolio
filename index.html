NourishAI · 2026 · AI product

You cannot search a delivery app for “high-protein, under 500 calories, not fried.”

The deeper blocker: restaurant menus carry no nutrition data at all, so a query like that has nothing to run against.

I built the missing data layer with an LLM Generate, Enrich, Load pipeline into Supabase, then a search where Claude Haiku turns the sentence into rules and Postgres ranks the dishes. The API key never touches the browser.

Illustrative data. Each dot is a dish, plotted by calories and protein, and lit when it passes the query.
